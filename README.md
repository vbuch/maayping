Maayping is a typing game where you type falling words on trees before they reach the leaf. Choose English or Bulgarian, type letters to match a word, and press Space or Enter to confirm. Complete 200 words to win while keeping escaped words under five.

Start the game locally: `python -m http.server 8000`

## Local anonymous play

When running locally (file:// or localhost/127.0.0.1/0.0.0.0), the game allows anonymous play without login and stores the profile locally in the browser. This mode is automatically disabled on hosted domains so the hosted version still requires login.
